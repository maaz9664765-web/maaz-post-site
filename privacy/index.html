Privacy Policy

What is collected: nothing. Maaz Post has no users other than its owner, no analytics, no cookies and no tracking.

Access tokens. When the owner connects a YouTube, Facebook, Instagram or TikTok account, the resulting access token is stored only on the owner's own computer and is used only to publish the owner's own videos. It is never sent anywhere else.

Videos. A video is uploaded directly from that computer to the chosen platform. For Instagram, whose API requires a public link, the file is placed on this site for a few minutes and then deleted automatically.

Deletion. Disconnecting an account in the tool deletes its stored token immediately. To revoke access from the platform side, use that platform's own app settings.
